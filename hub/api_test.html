Hack-box hub API test

Exercises the box API (/api/v1/*, bearer token) and the dashboard API (/dash/*). The hub serves this page at /dash/api_test.html, so calls are same-origin. Opened as a file, the browser blocks the calls (no CORS).

Careful: a successful box call (box token or enroll token) marks your address as a box, and the hub then refuses the dashboard and this page to it for 24 hours (403), until the hub restarts. Only localhost is exempt. Run box calls from the hub host itself, or from a machine you do not need the dashboard on.
